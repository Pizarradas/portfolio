01

Why I built it

Prove that my role can extend beyond hand-off.

The project is self-directed and deliberately interaction-heavy. I used it to explore how far I could take a product concept when AI-assisted development operates inside a system I already understand and govern.

02

System first

SYX provides the constraints before AI writes the implementation.

The project is built on SYX rather than generated as an isolated page. That gives the work an existing language for tokens, components, CSS architecture and reuse.

03

Interaction

Use motion and spatial interfaces as product tools.

The explorer combines mapping, 3D and motion technologies. The point in the portfolio is not the number of libraries; it is the ability to coordinate them into one navigable experience.

04

AI workflow

AI expands what I can execute directly.

Instead of presenting AI as authorship, I present it as an execution layer: I define the intent, constraints and system; AI helps accelerate implementation and iteration.

05

Takeaway

The deliverable is the running product.

This case demonstrates a different endpoint from a traditional design hand-off: a live interactive experience that can be inspected as product and code.
